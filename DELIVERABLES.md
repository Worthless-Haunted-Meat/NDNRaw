# What might emerge

Not a build checklist. Not a launch plan. Genesis first — rooms and people.
Anything below only shows up if the people in the room make it real.

## Already real

- The founding post (`data/raw/RawIdeas.txt`)
- The Facebook group: **NDNGenesis**
- This repo as a checkpoint log

## Might show up in the room

- **A strength catalog** — parents noticing what each young adult is actually
  good at / obsessed with. Could be a napkin. Could be a spreadsheet. Only
  with consent.
- **Talents that gel** — five musicians across neighborhoods become a band
  because someone in the parents' room noticed. Parents as first market: pay
  for a wedding gig. Not a program. Just parents helping.
- **A gig ledger** — if paid work happens, write it down. That's the proof.
- **Mentors on Zoom** — for edge cases the core room can't hold alone.
- **More cells** — 5–7 families in a neighborhood; other neighborhoods; other
  cities. Only if someone there feels this and starts their own genesis.

## Explicitly not building

- A guide
- A curriculum / syllabus
- A facilitation script for meetup #1
- A "City-in-a-Box" franchise kit
- Software before there's a living community
- Anything the young adults have to *sign up for*

If it needs a manual, it's already drifted off Genesis.
